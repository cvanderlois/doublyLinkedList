# LinkedList Implementation

## Description
A program that allows the user to buy tickets for a train. Prints the information
of each wagon on the train displaying the capacity and the current
number of tickets bought for each wagon. Displays the wagon with
the least number of tickets bought.

## Technologies Used
- Java
- IntelliJ IDEA

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Build the project.
4. Run the main class.

## Usage
Begin by buying tickets to a wagon of your choice (Wagon 1-10)
From here you may display the information of all ten wagons
then you may choose to display the wagon that has the most space available.
